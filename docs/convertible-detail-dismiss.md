# 可转债详情关闭交互（0.3.24）

## 问题与修复

转债列表、强赎/回售观察、散点图、公告及对比共用 `ConvertibleDetail`。
该面板显式设置 `closeOnBackdrop={false}`，覆盖了公共 `Modal` 默认的外侧点击关闭行为。

移除这一覆盖，复用 `Modal` 的遮罩点击判定、Esc、焦点恢复及拖选防误关机制。
外侧点击、Esc 和右上角关闭按钮都调用详情原有的 `close`：

- 仅查看资料时直接关闭。
- 编辑过公式、参数、现金流、条款或公告后，先提示是否放弃修改。
- 选择“继续编辑”保留当前输入；只有明确选择“放弃修改并关闭”才丢弃编辑。
- 试算和保存请求进行中，所有关闭入口保持不可用；请求失败后可继续编辑或关闭。
- 详情内的点击，以及从详情内开始、在遮罩上结束的文字拖选，不关闭面板。

放弃修改提示移至栏目下方、滚动内容之外，滚动长详情时仍可见。
提示中的放弃按钮也遵守保存/试算进行中的限制。

## 边界与升级复核

本次修改属于 L2 自定义转债模块的局部交互修复；未修改公共 `Modal`、API、
数据源优先级、金融公式、缓存、用户数据格式或 Mac 桌面退出实现。
合并上游时复核 `Modal` 的遮罩拖选防误关契约和 `ConvertibleDetail.close` 的编辑/请求保护。

回归用例位于 `frontend/src/custom/convertibles/ConvertibleDetail.test.tsx`，
覆盖三个关闭入口、取消放弃、重复请求关闭、拖选、试算/保存与失败恢复。
发布验证结果另随对应版本产物提供，不将尚未运行的检查写为通过。
