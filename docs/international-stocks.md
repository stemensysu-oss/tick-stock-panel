# 国际证券接入（0.3.20 候选版）

基于个人分支 0.3.19（本地 9f3c580，远端 7387e6b，二者程序树相同）。本版直接接线既有搜索、自选与个股分析，属于 L3；分析图表、指标、关键价位与 AI 流式输出沿用既有组件，不创建第二套页面。港股通路保留。

## 功能与来源

| 内容 | 美股 | 日股 |
|---|---|---|
| 代码 | AAPL.US（输入 AAPL/苹果），支持合法美股代码查元数据 | 7203.JP（接受7203/7203.T/丰田），初始目录含丰田和索尼 |
| 搜索/自选 | 原页面支持；国际证券单独读取缓存 | 原页面支持；公开补充源无需密钥；失败保留记录和未知价格 |
| 日K/关键价位 | TickFlow账户 → 扶摇（未公布相应契约，明确unsupported）→ TickFlow匿名历史服务 | 原两个源明确unsupported → 可选J-Quants V2个人API → Yahoo全球非正式公开图表 |
| 自选价格 | 先读取历史收盘，账户TickFlow报价有效时采用带原时点的快照 | Yahoo全球带来源时点的延迟快照，标注20分钟；不称实时 |
| AI | 使用同一份注明USD/日期/来源的不复权日K，依赖个人AI配置 | 同一份JPY日K；需个人AI配置，明确数据口径和缺失维度 |

日股默认可使用Yahoo全球非正式公开图表，不是Yahoo日本站。它无需密钥，原始数据不打包或转售，只供个人研究；其自动使用许可适用范围尚未获得官方确认，不代表正式数据授权。遇401、403、429不绕过、不换IP或cookie重试。使用者需留意提供方规则和持续可用性。J-Quants作为可选正式个人源，需要每位用户单独注册、订阅并在“个股分析→7203→日股数据源”保存本人的密钥。Free延迟12周，近期日终数据需相应计划，均不提供实时行情。默认不携带个人密钥。是否通过7203真实取数需以本次安装包的云端报告为准。

当前已实测的匿名美股通路返回AAPL历史数据。日股其他补充源实测：Stooq返回验证HTML，未绕过；TwelveData公开目录可查丰田，但demo价格接口401；J-Quants无key403。不抓取Yahoo日本，不以公开财务或证券目录冒充日K。

## 数据契约和兼容

- 国际价格与技术数据不写内地Parquet、不注入内地实时蜡烛、不进入内地涨跌停/分时/监控/分组统计。
- USD/JPY按市场契约标明；日K时间戳按America/New_York（含夏令时）或Asia/Tokyo转换，排除当地今天尚未完成的日期。
- TickFlow/J-Quants采用不复权字段。Yahoo全球仅使用quote OHLC，未使用adjclose，不擅自确认复权口径，页面与AI均注明来源未说明。分红、拆合股可能引起跳空，不当作实际收益。成交量保留来源单位，不推算金额与历史换手率，筹码支撑为空。
- 财务与直接新闻未接入；AI不补造缺失维度，实际模型调用需要已有个人AI配置。
- 自选沿用既有Parquet与分组字段，不改历史schema；国际代码保留市场后缀。
- 行情与分析缓存独立于内地热路径；分析缓存按代码和凭据身份隔离5分钟，热路径只读内存，失败保留上次成功资料并提示日期。
- J-Quants key沿用本地secrets_store原子保存，读取只返回configured布尔值，不回显密钥。发布文件、日志与安装包不含个人数据。

## 验证口径

单元测试中的人工样本、模型替身均只验证契约，不算真实行情或真实模型验证。云端安装检查要求真实AAPL与7203日K、搜索、自选、币种、时区、关键价位；真实模型仍需个人AI配置，云端AI契约用明确标记的替身。云端记录日股仅输出来源、行数、日期与能力状态，不输出原始日股行情序列，不向安装包夹带任何行情。

Naver和Nikkei虽技术上返回日K，但发现明确自动采集限制，没有接入默认回退链。JPX网页也不直接提取。Yahoo全球通用条款与API规则的适用性仍有不确定性，不把yfinance等第三方项目开源许可说成Yahoo数据授权。

正式源规格：[TickFlow](https://docs.tickflow.org/zh-Hans)、[J-Quants日K](https://jpx-jquants.com/en/spec/eq-bars-daily)、[套餐](https://jpx-jquants.com/en/spec/data-spec)、[个人使用许可](https://jpx-jquants.com/en/help/usage)。
