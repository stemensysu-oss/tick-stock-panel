# TSP 个人二开版 Windows 安装与升级

本分支的桌面版本为 **0.3.12**，基于上游 v0.3.11，包含基金研究与可转债工作台。
这里的 0.3.12 是 `stemensysu-oss/tick-stock-panel` 的个人二开版本号，不表示原作者发布了同名版本。

## 安装文件

从本仓库 `feature/funds-convertibles` 分支运行“桌面客户端发布”工作流，输入：

- version：`v0.3.12`
- platforms：`windows`
- prerelease：`false`（个人 fork 仅构建产物，此输入不会发布 Release）

完成后从成功运行的 Artifacts 下载 Windows 包，解压后运行 `TSP-Setup-x64-0.3.12.exe`。
不要用原作者 Release 里的安装包替代本分支安装包，否则原作者的程序文件不包含本分支扩展。
本次构建产物附带 SHA-256 和源提交信息；实际安装及接口检查结果以对应 Actions 运行记录为准。

安装目标是 Windows x64。桌面渲染依赖 Microsoft Edge WebView2 Runtime；已经正常运行 TSP 的机器通常已具备相应运行时。
若启动时提示缺少运行时，使用 Microsoft 官方 WebView2 安装入口，不要关闭系统安全检查。
本项目未配置 Windows 代码签名，不宣称安装器已签名。

## 已经装有 TSP：优先原目录覆盖升级

1. 等待正在进行的研究保存、同步或回测完成，正常退出旧 TSP。
2. 找到旧版快捷方式指向的 `TSP.exe`。将整个旧安装目录复制到独立的备份位置，备份位置不要放在原安装目录内。
3. 默认用户资料位于 `<安装目录>\data`。若曾设置 `DATA_DIR` 或外部 `.env` / `TICKFLOW_ENV_FILE`，也要备份实际数据目录及相应配置文件。备份应保留在本机，不要上传含密钥的配置。
4. 双击本分支安装器，核对安装路径为原 TSP 所在目录，按向导覆盖安装。安装器沿用原 AppId 并优先使用已有安装位置。
5. 启动后检查版本为 0.3.12、原有自选与配置仍在，并在菜单中打开“基金研究”和“可转债工作台”。若菜单曾被隐藏，可在“设置 → 菜单设置”中启用。
6. 在可转债页面验证导出 JSON 能保存到文件，关闭再打开后核对自选、排除项和列设置；确认旧版数据正常后再处理备份。

**不要求先卸载。** 同一目录覆盖安装只更新程序文件，安装载荷排除运行时 `data` 与 `.env`。
若确实先卸载，卸载器询问“是否同时删除用户数据”时选择“否”，然后仍安装到原目录。
不要为了让安装继续而删除数据目录。独立备份仍应先完成。

首次安装没有旧路径时，默认有 D 盘使用 `D:\TSP`，没有 D 盘使用 `%LOCALAPPDATA%\Programs\TSP`；也可以在向导中选择可写目录。

## 资料与偏好保存

| 内容 | 默认位置 |
|---|---|
| 股票自选、配置、行情、策略等原有资料 | 有效 `DATA_DIR` 内 |
| 可转债清单、现金流、条款、观察序列与公告 | `DATA_DIR\custom\convertibles\snapshot.json` |
| 桌面 WebView 持久化资料 | `DATA_DIR\webview` |
| 桌面启动日志 | `DATA_DIR\desktop.log` |

完整备份 `DATA_DIR` 是主要保全方式。可转债 JSON 导出是额外的研究备份，不包含原应用所有资料或 API Key。
可转债自选、排除项和可见列属于浏览器偏好；本版显式启用持久化 profile。
后端通常使用本机 3018 端口；端口被占用时会换端口，浏览器来源随之改变，因此不同端口的偏好可能不同。

## 更新与回退

个人二开版的内置更新检查指向自己的 fork，并隔离原作者更新缓存。当前工作流在 fork 上仅生成 Actions artifact，**不自动发布 Release 或创建标签**；尚无正式 Release 时，关于页沿用“检查失败 (网络受限?), 可直接前往 Releases”的通用提示。这也可能只是尚无正式发布，不表示安装失败或一定存在网络问题。

同步上游源码与安装更新是两件事。应在保留二开提交的分支中合并上游、解决冲突、验证后重新打包，不要把上游安装器覆盖到二开程序上。
如果需要回退，先退出新版本，另行保存升级后新增的研究资料，再恢复升级前程序与相应资料；不要直接混合覆盖不同时间的快照。

## 验证范围

构建流程在上传 Windows 安装包前检查静默安装、程序启动、主健康接口、基金及可转债扩展接口，并检查覆盖安装保留测试数据。
这些检查使用隔离临时目录和空配置，不使用用户的资料或 API Key，也不能代表用户电脑已完成安装。

实际数据权限仍需在安装后按已有设置验证：基金查询使用相应扶摇权限；可转债报价适配器使用 TickFlow 配置。条款、正股配对和公告不会由安装器自动填充。
完整功能和数据口径见 [可转债工作台](convertibles-workbench.md) 与 [基金和可转债说明](funds-convertibles.md)。
