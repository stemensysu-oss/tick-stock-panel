# 0.3.14：研究工作台行情补充源

0.3.15 新增港股、分红、新股、A/H 比价和上交所跨境回转基金来源，见[事件数据与港股](research-events-hk.md)。以下记录 0.3.14 的基线与原有补充机制。

修复三个入口只允许导入或配置 Key、却无法从空白状态取得数据的问题。复用现有扩展注册、研究存档与行情设置，不更改 A 股交易/盘口的数据源协议。

## 架构与优先级

`研究页面 → 领域服务 → ResearchMarketService / FallbackFundProvider → 主 API → 公开补充源`

- 价格请求按 **TickFlow → 扶摇 → 公开补充层（东方财富，异常时使用公开备用目录与腾讯报价）** 顺序执行。已有有效主源报价的标的不会再请求补充源覆盖；部分成功只把缺少报价的标的传给下一来源。
- 按数据集判断能力。TickFlow 当前未集成基金资料/净值/持仓，因此这些请求优先扶摇。扶摇未集成全市场转债/基金清单，也不把 A 股快照接口当成转债接口调用。
- 转债正股绑定、转股参考价不属于上述主 API 已集成能力：发现清单时允许公开补充源补齐这一独立能力，主 API 成功取得的价格与时点不被替换。
- 取数记录区分未配置、不支持、失败、空结果、成功；对外只返回固定错误文案，避免泄露供应商错误中的 Key。
- 公开请求只允许固定东方财富、新浪目录与腾讯报价域名，无 Cookie、无登录态，不访问集思录登录数据，不执行返回的 JavaScript。

## 能力矩阵

| 数据集 | TickFlow | 扶摇 | 最后补充源 | 边界 |
|---|---|---|---|---|
| 沪深转债清单/报价 | CN_Bond / 明确代码 | 未集成转债行情 | 东方财富 MK0354 | 只覆盖转债，不是全债市 |
| 已明确绑定的正股报价 | 明确代码 | A 股快照 | 东方财富明确 secids | 不从名称推断正股 |
| ETF 清单/价格 | CN_ETF | 未集成清单 | 公开 ETF 板块 | 不把 IOPV 当 NAV |
| LOF 清单/价格 | 未集成独立分类 | 未集成清单 | 公开 LOF 板块 | 净值缺失保持未知 |
| 现金管理 | 未集成独立分类 | 未集成清单 | 场内货币 ETF 板块 | 价格不是七日年化收益率 |
| REITs 清单/价格 | 未集成独立分类 | 未集成清单 | 沪深 REITs 分类 | 分红/现金流仍需独立披露 |
| 指数清单/点位 | CN_Index | 未集成全市场目录 | 沪深指数分类 | 以点计，保留扩展指数代码 |
| 基金资料 | 未集成 | 基金资料接口 | 公开基金概况页 | 概况更新时间未知 |
| 单位/复权净值 | 未集成 | 基金净值接口 | 公开历史单位净值 | 累计净值不冒充复权净值，按实际 20 条分页 |
| 披露持仓 | 未集成 | 基金持仓接口 | 最近报告期前十大股票 | 不是实时或完整持仓，公告日未知 |
| 套利事件、封闭基金分类、A/H 配对、T+0 QDII 资格、分红、新股 | 未集成对应专用数据集 | 未集成对应专用数据集 | 暂不自动填充 | 保留导入/演示，明确说明缺少可靠专用来源 |

“未集成”描述本项目实现，不声称供应商永远没有该能力。目录中的 available 表示已实现取数路径，网络、账号权限与实时性看当次结果。

公开补充层的容错：东方财富行情连接失败时，转债目录与正股绑定取公开债券资料接口，基金目录取新浪公开目录，再用腾讯明确代码报价补充。只采用有完整来源日期的价格，不把新浪的时分秒附会成今天。现金管理备用目录仅两只代表货币 ETF，指数仅六只代表指数；目录计数与实际返回不一致时明确提示，不承诺全市场覆盖。近 30 天没有可用来源时点的备用记录不纳入市场清单。

在线基金目录也失败时，使用随程序附带的 **2026-10-22 公开目录代码快照**，并在页面注明日期与新上市品种可能缺失。快照只含证券代码，不含任何价格或用户资料；显示行情仍必须取得当次成功的网络报价，无报价时保持未知。它与用户导入模式、虚构演示分别处理。云端构建先做行情网络预检，再从实际安装包验证所有已接通类别。

## 首次使用与数据保护

- 可转债：首次空清单自动尝试一次市场获取；失败可手动重试。初始化只对空存档生效，网络请求在写锁外，最后检查 revision 再原子写入。已有清单仅更新报价，不删除导入记录或研究资料。
- 基金：首次查询示例基金 510300.SH（真实来源，不是演示数据），可更换代码。各数据集独立显示来源、回退记录与缺失说明。
- 多资产：默认打开 ETF 市场行情。网络快照在内存缓存 60 秒，手动刷新绕过缓存；导入文件独立保存，网络刷新不覆盖。虚构演示保持隔离，离线预览没有行情联网入口。
- 失败不写成功缓存或覆盖旧快照；前端保留上次结果并显示失败。未知值不填零，不捏造收益率、公告、净值或交易资格。
- `quote_at` 是来源时点（TickFlow 报价时间、东方财富 f124 秒级报价时间；扶摇缺少行级时间时为服务端快照时点）；`fetched_at` 是抓取时间。盘后/休市不制造新成交时间。

## 接口与验证

- `POST /api/ext/convertibles/refresh`：带 `expected_revision`；空存档获取市场清单，已有存档更新报价。
- `GET /api/multi-asset/snapshot?category=etf&mode=market&force=true`：网络行情，不写导入文件。
- `/api/ext/funds/{ticker}/profile|nav|holdings`：逐数据集优先主 API，失败或无有效数据后补充。

单元测试用合成数据验证优先级、部分失败回退、缺失字段、净值分页、持仓报告期及存档并发保护。Windows 安装验证脚本只允许 GitHub 临时 Windows runner 执行，安装后从实际捆绑服务调用上述接口，检查真实公开数据数量、来源与日期，再验证覆盖安装后数据保留。无主 API 凭据的云端验证只证明公开补充源可访问，不声称已验证用户主 API 的账号权限。

缓存影响：独立市场内存缓存 60 秒；可转债原子存档；前端按类别与市场/导入/演示模式隔离 Query 缓存。基金按代码、区间隔离缓存。刷新不更新原 A 股行情缓存或用户导入文件。
