核心金融计算位于后端，生产界面通过 API 请求计算结果。离线预览为体验界面提供本地模拟接口；它的计算兼容性另行验证，不承担真实行情服务。

### 数据与计算的明确口径

人民币转债按每张面值 100 元处理。价格使用不复权元价格；百分数字段中 `20` 表示 `20%`，金额以元保存，表格按万元或亿元显示。缺失价格和无法计算的指标保持未知，不补成零或面值。

到期收益率使用实际日期、完整税前现金流和 ACT/365 年复利 IRR。同日应收款先合并，末期利息不重复追加；净价仅加一次明确的应计利息。回售收益率是用户输入日期和现金流的情景值。纯债折现率、波动率、无风险利率及股息率均需明确提供，评级不会自动对应隐含参数。

强赎及回售只统计用户提供并确认完整的实际交易日窗口。观察截止确认必须与计算日一致；已知到期日到达后不再给出当前价格条件达标状态。条件命中、董事会决定、正式公告及实施结果分别处理，不因价格达标自动修改公告状态或转股价。

### 编辑期间的数据基准

打开详情时记录当前清单版本，试算和保存均以该版本为基准。若清单已被行情刷新或其他编辑更新，服务端对带旧版本的请求返回 409，界面要求重新打开详情核对，不覆盖现有研究。只读试算不改变清单版本；修改输入后必须重新试算。

API 的 `analyze.expected_revision` 为可选字段，兼容早期调用；当前界面会传入该字段。研究保存、CSV 导入、行情刷新和备份恢复继续要求版本参数。

## 真实数据与平台限制

**本轮未使用真实有权限的 TickFlow Key 完成行情联调。** 状态中的“已配置”表示存在本地配置；实际连接、账号权限、证券覆盖与报价时间仍需在目标部署中通过刷新验证。缺 Key、无权限、限流、空数据、网络或格式错误已有明确处理，失败不会替换原清单。

实时适配器提供报价字段。正股配对、转股价、现金流、评级、剩余本金、基金持仓及公告仍需要可靠资料输入；尚未自动建立全市场条款数据库、基金持有转债反查库或公告识别服务。行情刷新不会补造这些内容。

没有集思录页面、Cookie 或会员接口抓取。集思录的字段和交互用于研究参考，数据由独立来源和用户资料进入；自有模型口径已在界面及说明中标注。此版本没有交易下单功能。

本轮交付源码及网页预览，**没有构建 Windows 原生安装包**。使用上游现成安装包不会自动得到本分支代码。后续桌面发行需从二开分支构建，并在目标平台验证。

## 用户数据、备份与恢复

服务端研究数据位于部署数据目录的 `custom/convertibles/snapshot.json`，实际写入上限为 32 MiB。完整 JSON 备份包含清单、现金流、条款、观察记录及公告；恢复前先预览和检查替换范围，确认后重新计算派生值并生成新版本。

CSV 替换基础清单时保留同一债券代码的研究记录；新 CSV 未包含的债券及研究记录会移出清单。正股绑定或证券类型发生不兼容变化时阻止静默复用。大批量替换、恢复备份和升级软件之前，应先下载完整 JSON。

筛选 CSV 只是选中显示字段的研究视图，不能代替完整备份。自选、排除名单和显示列属于当前浏览器偏好，不包含在服务端 JSON 中。恢复研究数据不包含密钥，也不改变软件设置。

当前原子替换和版本保护面向单个后端进程；多个独立进程不得共享同一数据目录并发写入。回退代码时应保留用户数据目录，并先确认旧版能读取当前数据格式。
