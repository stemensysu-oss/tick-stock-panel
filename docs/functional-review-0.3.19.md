# 0.3.19 功能与体验审查

范围：在现有基金、可转债、多资产和港股分析基础上，修复可复现的数据边界与交互问题，并增加内容字体设置。保留原有两家正式 API 优先、公开源补充的顺序；不抓取登录后的集思录数据。

## 本轮修复

- 正式基金最新股票持仓过滤非股票资产；公开旧持仓入口复用披露解析器，保留五位港股代码，只有源链接明确市场时标记 `.HK`。
- 货币基金公开收益失败进入统一错误边界，避免未处理的服务器错误与敏感异常泄露。
- 慢查询期间可切换其他基金；五类数据均参与刷新状态；刷新失败保留已成功的数据并显示错误。
- 货币基金加载、空区间和失败状态采用收益口径；未知分类不展示成净值；缺失收益点不冒充有效数据。
- 展示申赎规则生效日。持仓类型、报告期、代码及净值区间保持查询隔离。
- 转债联网条款页隐藏不相关的试算、保存按钮；保留人工草稿、关闭提醒、版本冲突保护。联网读取失败保留上一份原文。
- 多资产强制刷新完成后取消较早的后台读取，防止迟到响应覆盖新行情。

## 内容字体

入口：设置 → 系统设置 → 界面 → 内容字体。

- 字号基准 14–22px，默认 18px，沿用此前放大一号的外观并按比例保留字号层次。
- 原有字体、系统字体、微软雅黑优先、苹方优先、思源黑体优先。仅使用本机字库，缺少时使用后备字体。
- 正文、列表及内容弹窗即时预览；侧栏菜单不受影响，行情数字保留等宽字体，图表画布内字号保持原样。
- 原子合并保存，重启恢复；保存失败回滚；读取失败可重试；一键恢复默认值。
- 后端严格校验输入。字体保存完成前后均取消旧偏好读取，避免迟到请求覆盖新值。

## 验证与边界

回归覆盖数据源顺序、错误脱敏、缓存隔离、稀疏收益、并发保存、迟到响应、手工资料保留与只读页面操作。

安装验证在一次性云端 Windows、Apple Silicon macOS 执行：真实应用窗口、公开联网、覆盖或替换升级、字体设置两次启动保持。构建结果以对应安装包旁的 `.build.json` 为准，脚本存在不等于实际通过。

本轮不宣称全部市场资料完整：公开持仓是披露子集，资料有延迟；通用申赎规则有渠道范围；转债源条款不自动改写人工现金流，强赎公告链与达标天数仍有缺项。真实 AI 回答和个人付费 API 权限需已有个人配置，云端只验证模型调用契约、缺少配置提示及公开补充路径。
