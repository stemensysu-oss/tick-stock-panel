# 可转债列表字段补齐（0.3.21）

旧版市场清单只初始化报价、正股绑定与参考转股价，联网条款仅在单独详情展示；纯债列只支持人工现金流估值，且默认没有显示该列。此次为已有清单、新建清单增加独立的只读参考覆盖层，读取失败不影响报价、导入与人工研究。

| 字段 | 数据与口径 |
| --- | --- |
| 到期日期、剩余年限、评级、转股起止、票息、条款 | `RPT_BOND_CB_LIST`，已上市且未来到期才使用公开 EXPIRE_DATE；原始人工字段优先。剩余年限为显示的到期日距清单计算日自然日/365。 |
| 纯债价值、估值日、估值日收盘及纯债溢价率 | `RPTA_WEB_KZZ_LS` 最近可用估值日，验证 ZCODE、SECUCODE、DATE；最多接受30日内快照，超过7日提示较旧。估值日期不借用抓取日或最新行情日。 |
| 强赎/回售触发价、到期赎回价 | 公开报价 f240/f239/f241，仅作为独立参考，不用它推断条款已经触发；源失败保持未知，不默认130%、70%或100元。 |
| 自建纯债估值、期权、到期/回售收益率 | 原计算器及人工输入保持原有逻辑，完整现金流、价格口径、折现率或波动率不足仍不计算。表中自建纯债模型优先，公开模型兜底，明确两者来源与数据日。 |
| 正股PB、基金持仓、流通市值等 | 仍使用明确导入字段；本次没有宣称补齐全部机构持仓、隐含波动率或实时财务口径。 |

现有 TickFlow、扶摇集成契约均未提供完整转债条款与纯债估值，参考查询 attempts 标明 unsupported 后使用公开源；不编造主API端点。原报价仍优先 TickFlow→扶摇→公开源，本次参考服务不会替换成功的原API报价。没有请求集思录、会员页面、登录态或绕过访问控制。

纯债参考值的供应商折现曲线、信用假设、净价/全价口径未披露，展示为“公开模型参考”，不冒充本地现金流模型或保证收益。到期收益率不由纯债价值反推。估值日收盘与纯债溢价率成套展示，不把历史源溢价率当作当前行情溢价率。到期赎回金额是否含末息需核对条款，不自动补加利息。

已终止/退市的 EXPIRE_DATE 可能已改为提前赎回日（例如113063），保留为 source_end_date，不显示成原合同到期日，也不展示为当前纯债估值。即便尚未退市，未来结束日也必须与起息日及源明确提供的整数期限一致（允许7天日期顺延差），否则不当作原合同到期日；此校验不自动生成到期日期。转股截止日另列，不能把其自动当到期支付日。例如113052公开到期日为2027-12-27，转股截止2027-12-26。

前端按全部现有代码自动查询，行情刷新后重新读取，失败保留同代码最近成功的查询结果与原获取日期；不沿用另一组代码的数据。后端每100只分批，最近估值日查询后按日读取，不为每只下载完整历史。5分钟、16组有界内存缓存深拷贝。请求最大2000只，限定代码族和固定公开域名；异常内容不会回传。当前参考资料非历史时点可得数据，不应用于历史回测。

前端常用列增加纯债价值、口径、估值日期、剩余年限和到期赎回价；原默认列自动升级，自定义列、自选和排除保留。显示列数量按实际列计算。纯债CSV导出自动附带口径及日期；JSON备份仍为原人工研究快照，联网参考不写入、不给旧研究加上虚假的人工确认。详情分别显示联网参考与已保存的试算。

来源定位：[AKShare源码](https://github.com/akfamily/akshare/blob/main/akshare/bond/bond_zh_cov.py)、[东方财富兴业转债资料](https://data.eastmoney.com/kzz/detail/113052.html)、[上交所兴业转债概况](https://www.sse.com.cn/assortment/bonds/list/bondinfo/basic/index.shtml?BOND_CODE=113052&BOND_TYPE=%E5%85%A8%E9%83%A8)。未引入AKShare运行依赖。云端安装验证包含113052、127068带日期估值、到期日与113063退市防误用，测试使用公开源，不使用个人付费API密钥。

界面按用户提供集思录截图调整为紧凑单行表：取消名称下第二行状态，状态与全名移至悬停说明；数字列78px、代码108px、名称100px、日期98px（均随用户字号等比例扩展），单元格上下6px、左右6px。排序/自选/对比保持可操作，代码名称固定；强赎达标保留名称提示色。对比/条款表也缩小单元格留白。实际行高随字体计算，不固定裁切。
