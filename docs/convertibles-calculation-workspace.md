## 用户目标及完成条件

1. 截图中的报价、正股、转股、估值、触发、持仓、期限、规模、收益指标逐项有入口、单位、来源/公式及缺项原因；不以发行规模填剩余规模，不伪造持仓和模型参数。
2. 纯债提供独立的个人计算，可修改现金流、折现率及公式；机构评级只读，个人评级/信用假设另存，不伪装成机构评级。
3. 计算项显示公式、输入、结果、单位和依赖。支持全局模板与单只覆盖，预览不写入，保存走原 revision/CAS，错误公式不能悄悄沿用旧值。
4. 顶部连接、估值参考、统计与筛选一起压缩；保留可调字体、键盘可达、全部字段、导出与备份，桌面和窄屏检查。
5. 服务/数据源/公式/接口测试、前端构建与交互、云端原生 Windows/Mac 安装及升级验证通过后交付。个人账户真实AI生成不属于本次验证。

## 数据与计算矩阵

| 指标 | 来源或公式 | 区分与要求 |
| --- | --- | --- |
| 价格、涨跌、成交额、换手 | 继续原 API 优先链 | 不以补充参考报价覆盖成功主报价 |
| 正股代码、期限、票息、评级机构与评级 | 已有条款批量服务 | 原始到期日仍验证起息日/期限，提前终止不冒充到期 |
| 剩余规模 | 公开转债存续张数 × 面值；保留直接人工资料 | 样本 f38/39 与单笔 f84/85 一致，市值/单张报价作单位一致性核对；不是发行规模，来源数量统计日未知不借用报价日 |
| 正股 PB、流通市值 | 独立股票基础指标补充 | 明确绑定与日期，不改变主报价；PB可为负 |
| 转股价值、溢价、双低、占流通市值比、剩余年限 | 默认算术模板，允许用户覆盖 | 百分数20=20%，本金/正股流通市值；年限按自然日/365 |
| 纯债参考 | 已有公开估值与估值日 | 外部模型参数未披露，不假装可修改外部算法 |
| 个人纯债、到期收益 | 完整手工现金流优先；严格识别的合同计划现金流可用于明确标注的计划情景 | 按每张税前应收，末次兑付含末息时不重复加；节假日顺延与实际公告待核；持有到期且未提前赎回假设必须展示 |
| 期权价值 | 简化 B-S 与可编辑参数 | 实际波动率/用户情景波动率分开，缺参数不能编造；不含全部信用及赎回/回售条款 |
| 回售触发、强赎触发 | 条款/公开参考或个人比例×转股价 | 触发价不代表达到条件、也不代表实施 |
| 回售收益 | 用户明确回售日期、金额及权利情景 | 无权利与现金流时标缺项；不自动声称可回售 |
| 基金持仓比例 | 有报告期和来源的持仓或人工覆盖 | 公开持仓子集不承诺全量，不能把十大持有人/股票持仓当作全部转债基金持仓 |

## 计算边界

新增限定在转债研究中的算术解释器，逐 AST 节点求值，不使用 Python eval/exec，不允许属性、索引、导入、文件操作、循环、推导式和任意函数。长度512、节点128、公式32、参数128、有限数值与幂指数上限；依赖先检测循环再计算。只暴露列出的数学函数及复用既有现金流/IRR/B-S 的闭包函数。输入缺失与零分开，缺项、数值错误、语法错误分别展示。

全局模板与个人参数、单只覆盖为向后兼容的可选字段；原字段缺失使用旧行为。公式和参数属于用户研究资料，随JSON备份恢复。公开参考仍只读独立缓存；个人计算不能进入跨账户公共缓存。计算日、研究 revision、配置版本进入前端查询键。计划现金流与手工已确认现金流分开，预览不会写成用户已确认资料。
