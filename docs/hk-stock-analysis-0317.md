# 港股个股分析（0.3.17）

## 入口与数据链

个股分析原搜索只请求stock,index，本版加入hk，复用已有五位代码及品牌别名搜索。00700/00700.HK/腾讯/腾讯科技选择后统一保留00700.HK。

港股图表与AI使用同一独立快照：`research_hk_daily`供应商标准化→`hk_stock_analysis`缓存、通用指标与关键价位→`stock_analysis` HTTP/NDJSON→原个股分析页及报告store。港股不进入A股日线存储、复权/涨跌停/信号或财务读取。原内地分支保留。此为L3核心入口接线加小粒度provider/service，不复制整个页面或分析引擎。

| 能力 | 优先顺序与边界 |
| --- | --- |
| 搜索 | 复用0.3.16的明确代码报价/证券目录及公开建议链 |
| 日K | TickFlow SDK klines.get(symbol,period=1d,adjust=none)→扶摇（已公开契约为A股价格及港股IPO，此项标为不支持）→腾讯公开日K |
| 币种 | 独立报价链明确确认HKD；不从.HK后缀猜币种，人民币柜台不混用 |
| 指标 | 复用纯价格通用compute_indicators，计算MA/MACD/KDJ/RSI/BOLL/ATR，不执行A股compute_signals/涨跌停流水线 |
| 价位 | 复用原计算器；无历史换手率时停用sr筹码组，仍有pivot/extreme/BOLL/Keltner/ATR/gap/fib/round |
| AI | 复用已配置AI服务、原流式协议及报告保存；独立港股提示词约束来源、样本日期、币种、缺失财务新闻与非交易指令 |

## 口径与安全边界

历史日K为**不复权港元价格**，不把累计净值或A股复权系数用于港股。只采用北京时间/香港日期今天之前的日期，最多展示250根；当天报价快照独立显示自己的报价时点，不冒充历史最后收盘。分红拆合股可能产生跳空，AI必须说明不复权局限。当前没有完整公司行动调整因子，不声称前复权总收益分析。

成交量保留来源原单位，供同一来源序列查看；不换算成成交额/手数或换手率，也不由其推断持仓。日K标准化拒绝空、NaN/Inf、非正价格、错误高低关系、负成交量、重复及未来日期，少于30条不做分析。供应商返回的原始错误不对外输出。

快照按代码及主源凭据配置的哈希区分，5分钟缓存、最多32项，返回深拷贝；强制刷新失败不覆盖成功快照。HTTP在同步worker，AI加载数据走anyio工作线程，不阻塞事件循环；没有将逐证券网络请求加入自选enriched/SSE热路径。图表系列提取从原API移至纯共享模块，原私有别名兼容保留。

AI提示词只输入真实已取到的数据与关键价位，港股财务、基本面与直接新闻缺失时明确不可评估，不套用A股涨跌停、连板、T+1与人民币规则。港股点位提醒不在本次接入范围，避免提交到原内地监控链路。AI未配置/失败返回明确错误，不保存虚假成功报告。

## 验证分层

- 真实公开网络验证：00700.HK的日K、指标及价位；报价与来源时点。
- 本地定向测试：供应商顺序、首源成功不调补充、结构/价格/日期拒绝、缓存/强制失败、币种、HTTP日K/levels/AI流、数据输入、测试模型成功、错误脱敏、报告持久化；原内地日期/ETF/指数文案、自选和补充源回归。
- 前端集成：实际StockAnalysis组件搜索、选择、港股chart/level props、AI请求代码、主数据失败隔离及强制刷新失败保留。
- 云端单独运行相同契约测试，**模型是明确标记的测试替身，不是线上大模型调用**。
- 安装后的应用另跑真实日K与价位、无AI配置错误、测试报告保存和覆盖升级后的记录保留。云端不带个人AI密钥；实际模型回答质量与个人模型权限不能声称已验证。
