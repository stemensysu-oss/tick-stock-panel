# 0.3.15：事件数据、跨境比价与港股

本次沿用既有 L2 多资产工作台及研究报价路由，独立数据集不写入用户导入存档。内容区文字扩大 2px，侧栏和菜单文字保持原尺寸。

## 数据集与优先顺序

| 功能 | 原有 API 优先能力 | 最后公开补充 | 范围与口径 |
|---|---|---|---|
| 港股 | TickFlow `HK_Equity` / 明确代码；扶摇已集成契约无港股快照 | 公开港股目录与腾讯明确代码延迟行情 | 五位 `.HK` 代码、港元价格；范围以页面说明为准，不声称全港交所行情 |
| 分红 | 两个主 API 尚未集成全市场分红计划日历；历史除权事件不冒充计划 | 东方财富 `RPT_SHAREBONUS_DET` | 最近有限公告窗口，每股税前金额按明确每十股字段除十，保留方案进度、报告期和登记/除息日；不把预案当已支付，不据此计算滚动股息率 |
| 新股 | TickFlow 未集成日历；扶摇 `/api/a-share/ipo/calendar-list` 优先 | 东方财富 `RPTA_APP_IPOAPPLY` | 沪深及北交所申购/上市事件，未知发行价留空；状态和来源日期保留，申购资格仍需核对 |
| A/H 比价 | 证券价格按 TickFlow → 扶摇 → 公开补充路由 | 明确 A/H 配对目录、两地报价、独立港元兑人民币报价 | 仅同日 A 价、H 价与 CNY/HKD 汇率才计算 `(A/(H×汇率)-1)×100`；每项来源与时点可查，异日不混算 |
| T+0 跨境基金 / QDII 研究 | 资格目录未集成主 API；价格仍优先原两个 API | 上交所明确 `SWING_TRADE=是` 的跨境 ETF / LOF 名单与公开报价 | 仅上交所范围，含 QDII 与港股通产品，不能把“跨境”统一当作 QDII。资格不代表当前可申赎、可成交或未停牌 |

未集成能力会在来源追踪中列出“不支持”，未配置凭据列出“未配置”。这不是声称供应商永远不提供相关产品，而是当前适配契约的事实。成功主源报价不会被补充源覆盖，部分失败只补缺少的标的。云端无个人主 API 凭据时只能实证公开补充链路，主源优先顺序由契约测试验证。

## 日期、失败与缓存

每个独立目录、价格、汇率和事件都有各自的日期含义。抓取时间不是报价时点，计划日不是实施日。首次空结果、分页异常和网络中断不会写成成功数据，行情缓存 60 秒、事件缓存 5 分钟，手动刷新均绕过缓存，导入数据与虚构演示保持隔离。

资格或配对目录失败时，允许使用注明日期的公开代码目录快照，快照不含价格；页面必须说明目录待复核。实际行情仍须本次网络请求成功。没有独立净值、IOPV、申赎限制来源时保留未知，不计算净值溢价。

港股上一版缺失的原因是市场分类和代码解析只覆盖沪深。新增港股路径与 A 股交易/盘口引擎隔离，不把香港交易制度套到现有 A 股下单或回测规则中。

## 验证

测试覆盖优先级、原 API 未配置/不支持/失败、部分补缺、代码与币种、日期不一致、分红单位、未知发行价、资格证据、旧存档与用户导入隔离。实际安装验证只在 GitHub 临时 Windows 电脑执行，并在首次安装和覆盖升级后分别请求新增五类数据；不安装或卸载用户电脑上的 TSP。
